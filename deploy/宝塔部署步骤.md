# pawhope.cn 宝塔部署步骤

前提：DNS 已指向 `49.233.199.58`（已确认生效）。

## 1. 上传代码

1. 宝塔 → 文件 → 进入 `/www/wwwroot/`
2. 新建目录 `pawhope`
3. 把本机项目整包上传进去（至少要有 `public/`、`server/`、`package.json`）
4. 最终路径类似：`/www/wwwroot/pawhope/server/index.js`

## 2. 安装 Node 并启动

1. 宝塔 → 软件商店 → 安装 **PM2 管理器**（或 Node 版本管理）
2. 终端里执行：

```bash
cd /www/wwwroot/pawhope
node -v
# 需要 >= 18；不够就用宝塔 Node 版本管理切到 18/20
pm2 start server/index.js --name pawhope
pm2 save
pm2 startup
```

3. 本机自测：

```bash
curl -I http://127.0.0.1:3680/
```

应返回 `200`。

## 3. 新建站点（不影响原有域名）

1. 宝塔 → 网站 → 添加站点
2. 域名：`pawhope.cn`（可再填一行 `www.pawhope.cn`）
3. 根目录随意（会被反代覆盖），PHP 选纯静态
4. 提交

## 4. 反向代理

1. 点开站点 `pawhope.cn` → **反向代理** → 添加
2. 代理名称：`pawhope`
3. 目标 URL：`http://127.0.0.1:3680`
4. 发送域名：`$host`
5. 保存

## 5. HTTPS

1. 站点 → **SSL** → Let's Encrypt（或腾讯云/阿里云证书）
2. 勾选 `pawhope.cn`、`www.pawhope.cn`
3. 申请成功后开启 **强制 HTTPS**

若申请失败，多半是：
- 国内服务器未完成 ICP 备案
- 80 端口被占用/防火墙未放行
- DNS 未完全生效

## 6. 安全组 / 防火墙

云厂商控制台放行：`80`、`443`（入站）。  
`3680` **不要**对外开放，只让 Nginx 本机访问。

## 7. 验收

浏览器打开：

- `https://pawhope.cn`
- 手机 Safari/Chrome → 添加到主屏幕

应能看到爪印日记首页。
